# ⚡ Quick Start: Setting Working Directory 

## 🎯 Goal
Get your analysis running with automatic Desktop folder setup.

---

## 3 Super Simple Steps

### Step 1: Run First Chunk (1 minute)

**In RStudio:**
1. Open: `casm3_descriptive_analysis.Rmd`
2. Find: "setup-working-directory" chunk
3. Click: Green ▶️ play button
4. Console shows:
```
✓ Created folder on Desktop: CASm3_groupwork
✓ Working directory set to: /Users/yourname/Desktop/CASm3_groupwork
```

**What happened:**
- Folder created on your Desktop (you can see it!)
- R knows to use that folder

### Step 2: Copy CSV File (1 minute)

1. Look at your Desktop → see `CASm3_groupwork` folder
2. Copy: `cas_digital_biom_outcomes.csv`
3. Paste it in that folder
4. Done! ✅

### Step 3: Load Data (1 minute)

**In RStudio:**
1. Find: "load-data" chunk
2. Click: Green ▶️ play button
3. Console shows:
```
✓ Data loaded successfully!
File: cas_digital_biom_outcomes.csv
Location: /Users/yourname/Desktop/CASAnalysis_GroupX
Dimensions: 968 rows × 18 columns
```
